# AI-Archaeology-Course-Goettingen
AI &amp; Archeology WiSe 2026/27

Welcome to the official repository for the course **Artificial Intelligence for Archaeology** at the University of Göttingen (WiSe 2026/27).

## Repository Purpose
This repository serves as the central **basecamp** for the course. Throughout the semester, it will be used to host and distribute:
- Course materials (slides, datasets, and reading lists).
- Code snippets and Jupyter Notebooks for practical sessions.
- Open-source tools for archaeological data processing (e.g., PyPottery, PyPotteryScan, and text analysis scripts).
- Instructions for hands-on assignments.
